## 🚀 Featured Financial & AI Projects

### 📈 MASI Forecasting — *Quantitative Market Intelligence*
> **Focus:** Time Series Econometrics • Market Regime Detection • Predictive Alpha
* **The Problem:** Financial markets exhibit non-linear shifting behaviors (regimes) that traditional linear models fail to capture.
* **The Architecture:** Designed a hybrid mathematical framework for the Moroccan Stock Market (MASI) using **Hidden Markov Models (HMM)** for regime tracking and deep **LSTM Networks** for price-trend projections.
* **Feature Engineering:** Integrated signal processing arrays including custom volatility matrices, **RSI**, and **MACD** technical layers.
* *Stack:* `Python` • `TensorFlow` • `Scikit-Learn` • `Pandas` • `Matplotlib`
* 🔗 **[Explore Quant Framework](https://github.com/jaafarelkouhen/masi-forecasting)**

### 🔍 RAG MASI — *Generative Financial Analyst*
> **Focus:** Natural Language Processing (NLP) • Vectorized Market Intelligence
* **The Problem:** Extracting actionable context from dense regulatory filings and earnings reports is traditionally human-capital intensive.
* **The Architecture:** Engineered a Retrieval-Augmented Generation (RAG) agent mapping structured financial knowledge into low-latency vector beds. Utilizes custom indexing to eliminate context drift and model hallucinations during audit scenarios.
* *Stack:* `Python` • `LangChain` • `FAISS` • `OpenAI API` • `FastAPI`
* 🔗 **[Explore System Architecture](https://github.com/jaafarelkouhen/rag-masi)**

### 📊 MASI Analytics Dashboard — *Portfolio & Risk Visualization*
> **Focus:** Business Intelligence • Market Telemetry Pipeline
* **The Problem:** Disconnected financial datasets require visual correlation to empower quick capital deployment decisions.
* **The Architecture:** Built a performant financial dashboard serving live technical indicators, trend dynamics, and interactive portfolio exploratory graphs.
* *Stack:* `Python` • `Dash` • `Plotly` • `SQLite` • `Pandas`
* 🔗 **[Explore Dashboard](https://github.com/jaafarelkouhen/dashbord-masi-forecasting)**

### 🤖 Multi-Agent Enterprise Intelligence Platform
